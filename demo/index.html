    Prototype. Scam Shield is a test tool, not a guarantee. A “safe-looking” result does not prove a message is safe, and a “likely scam” result does not prove it is a scam. When in doubt, do not tap links or send money — call the company or person using a number you already trust.

    This is Scam Shield version 5. In held-out tests it caught 96.7% of modern (2025) scam texts, 95.8% of older spam texts, and 97.6% of examples from the newest 2026 scam families, while flagging only 0.29% of normal messages by mistake. On scam texts rewritten with real-looking links and numbers instead of placeholders, it caught 94.6%.

    Version 5 learned the difference between a message that tells you something and one that asks you to hand something over. Everyday messages like bank alerts, appointment reminders, and verification codes used to be flagged by mistake 53% of the time — now that false-alarm rate on those messages is 0.35%. A real verification code (Example 7 above) is fine; a message asking you to send a code to someone else is not.
